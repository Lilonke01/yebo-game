## Browser installation alternative

# Install Yebo on Android and iPhone

Game link: https://yebo-shopping-adventure-phone.lushbull5.chatgpt.site

This link is private to the owner account. Sign in if asked when opening it on your phone.

Android: open the link in Chrome, open its menu, and choose Install app or Add to Home screen.
iPhone: open the link in Safari, tap Share, then Add to Home Screen. Turn on Open as Web App if offered, then tap Add.

Open Yebo from its new home-screen icon. In Options, expand Install & play offline. Choose English, English + Afrikaans, or English + isiZulu, then tap Save for offline play. Keep the game open on Wi-Fi until it says Ready. English reading is included in every download. English pictures and voices need about 82 MB; another voice language increases the download.

Progress is saved on each device separately. Your computer's progress does not transfer automatically. Clearing browser/app website storage removes downloaded files and progress. Phones may reclaim storage when space is low; reopen online and save again if needed.

This is an installable web app, with no App Store or Play Store download. First installation and offline preparation need internet. Real Android and iPhone hardware installation has not been tested from this computer.

Local desktop play still works through Start Yebo.cmd. The computer's 127.0.0.1 link cannot be opened from another device.
