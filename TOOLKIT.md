# Narrative game toolkit

Use Twine to plan branching stories and make browser-based interactive fiction.
Use Ren'Py for visual novels with characters, dialogue, and choices.
Use Godot for a narrative game with exploration, puzzles, or custom gameplay.
Use Inky to write and test ink dialogue scripts.
Use Krita for backgrounds and character art, Inkscape for vector graphics, Blender for 3D assets, and Audacity for voice and sound editing.

Git, GitHub Desktop, and Visual Studio Code were already installed.

Installation outcomes are recorded in installation-results.json when the installation run completes.
